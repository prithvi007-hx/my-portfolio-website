# My Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Personalize it

Replace the sample name, bio, project examples, email address, and social links in `index.html` with your own details.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

In your repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will show your public website link when deployment is ready.
